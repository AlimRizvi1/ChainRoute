Explain the AI in three steps

  1. Learn from simulated trips

    Generate 30,000 lognormal transit outcomes for grain, coal, and steel. Train logistic regression on 24,000 examples; keep 6,000 separate for evaluation.

  2. Estimate on-time probability

    The inputs are deadline slack divided by route transit time, and a fixed variability value for the cargo. Logistic regression converts the learned weighted sum into a probability between 0 and 1.

  3. Allocate and rank

    Google OR-Tools CP-SAT searches feasible wagon assignments under capacity, compatibility, route, and timing constraints. The engine applies ML probabilities and ranks candidate plans with the chosen weights. CP-SAT is an optimizer, not a second trained model.

Loading the saved coefficients…

The JSON artifact contains the learned coefficients and model version. Inference runs in Python without retraining. If the model is missing or cargo is unknown, the prediction layer has a labeled heuristic fallback.

This holdout comes from the same simulator as training. Real delivery history, validation on future trips, and probability calibration on field data are still needed before claiming operational accuracy. Today’s dates are not suitable for this fixed-clock demo: they can saturate predictions near 100%.
